Publications
Contextual Observer Grounding: Evaluating Situated Spatial Reasoning in Vision-Language Models
Mimo Shirasaka, Haochen Zhang, and Yonatan Bisk
EMNLP Findings, 2026
Website / Code / Dataset

POVBench evaluates contextual observer grounding: recovering a speaker's viewpoint from contextual cues and localizing an object they described from that viewpoint. State-of-the-art VLMs struggle, and explicitly decomposing the reasoning improves localization.
INSIGHT: A Feedback System for Learning Expert Reasoning-Action Sequences in Industrial Plant Inspection
Mimo Shirasaka, Kohei Kaminishi, Shinji Kanda, Yasushi Umeda, Masayoshi Kinoshita, Risa Koda, Shota Shimizu, and Jun Ota
Augmented Humans, 2026 Poster and Demo
Paper

INSIGHT combines VR-based industrial plant inspection with post-task action-reasoning feedback, helping novices learn expert reasoning-action sequences and improve anomaly detection performance.
Robust and Resilient Soft Robotic Object Insertion with Compliance-Enabled Contact Formation and Failure Recovery
Mimo Shirasaka, Cristian C. Beltran-Hernandez, Masashi Hamaya, and Yoshitaka Ushiku
ICRA, 2026
Paper

The Compliance Enabled Failure Recovery system integrates automated failure recovery strategies into compliance-enabled soft robotic object insertion, making the system robust and resilient to uncertainty and environmental variations.
SPARK: Graph-Based Online Semantic Integration System for Robot Task Planning
Mimo Shirasaka, Yuya Ikeda, Tatsuya Matsushima, Yutaka Matsuo, and Yusuke Iwasawa
RSS Workshop, 2024 Poster — Best Poster Award
Paper

The SPARK system extracts semantic information from environment cues (verbal, written text, and gesture) and updates the scene graph online for robot task planning.
Self-Recovery Prompting: Promptable General Purpose Service Robot System with Foundation Models and Self-Recovery
Mimo Shirasaka, Tatsuya Matsushima, Soshi Tsunashima, Yuya Ikeda, Aoi Horo, So Ikoma, Chikaha Tsuji, Hikaru Wada, Tsunekazu Omija, Dai Komukai, Yutaka Matsuo, and Yusuke Iwasawa
ICRA, 2024 Oral, Poster, Demo
Paper / Website

The self-recovery pipeline's automatic prompt updates enable failure recovery and task completion in general-purpose home robot tasks.
